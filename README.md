# OpenNutriTracker web prototype

A frontend-only Next.js translation of the Flutter app. It keeps the warm-neutral palette, Nunito typography, macro colors, rounded surfaces, calorie ring, and mobile bottom navigation while adding a responsive desktop layout.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The prototype uses static mock data. The primary navigation, diary date selection, trend filters, theme toggle, settings controls, and add-entry sheet are interactive and ready to connect to real data later.
